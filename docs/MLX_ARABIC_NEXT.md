# المحرك العربي المحلي التجريبي

أضيف Qwen3-4B-Instruct-2507-4bit إلى تطبيق Xcode بصورة اختيارية. المحرك مكتوب بـSwift/MLX؛ نجحت تجربة Swift مستقلة على Mac تحت منع الشبكة في Run 11. نجحت ترجمة iOS في Run 12 وRun 13. فشل Run 13 عند مسارات MLX غير المدعومة في Simulator؛ أضيفت حماية صريحة ورسالة عدم دعم، وتُختبر معالجة الملفات والواجهة هناك فقط. نجح Run 15 على `4ad47e97401996ea451d527e675e7eff7046c722`: 40 وحدة و4 رحلات UI وبناء الجهاز والمحاكي و8 إجابات Swift Mac مع حظر الشبكة. قمة MLX في Mac 2,564,247,224 بايت، وcache بعد unload صفر؛ ليست قياسات هاتف. بقي شرح الاسترجاع النشط أقل دقة، لذلك لا اعتماد إنتاجي. راجع [سجل التنفيذ](EXECUTION_2026-11-01.md) للنتيجة الدقيقة. لا يعني ذلك تثبيتًا أو قياسًا على هاتف المستخدم.

## الأوزان والخصوصية

المصدر `mlx-community/Qwen3-4B-Instruct-2507-4bit` مثبت عند `50d427756c6b1b2fe0c0a10f67fbda1fc8e82c1b`. أصل النموذج Qwen بترخيص Apache-2.0؛ راجع [manifest](qwen-model-manifest.json) لمصادر الملفات وحجومها وبصماتها. النسخة المجتمعية تحويل منشور، وليست تحويلًا نفذناه بأنفسنا.

التنزيل اختياري من شاشة «ذكاء محلي»، نحو 2.28GB، عبر Wi-Fi، ويتطلب مساحة 5GB وRAM لا تقل عن 8GB وفق شرط تجريبي محافظ. الأوزان خارج IPA وخارج backup الملاحظات وiCloud backup. URLSession يستخدم للتنزيل العام فقط؛ نص المستخدم لا يرسل إلى خدمة نموذج. التوليد يحمل الأوزان والـtokenizer من ملفات محلية. إثبات منع الشبكة الكامل تم على Mac. MLX لا يدعم استدلال Simulator وفق [توثيق الإصدار المثبت](https://swiftpackageindex.com/ml-explore/mlx-swift/0.32.3/documentation/mlx/running-on-ios)؛ لا يختبر المحاكي الاستدلال ولا يدعيه. يلزم iPhone فعلي لتقييم المسار على iOS.

## القيود والاختبار التالي

- توليد محدود، وإلغاء عند الخلفية/تحذير الذاكرة/حرارة مرتفعة، وبوابة تمنع تشغيل Apple وQwen معًا.
- ملاءمة 8GB شرط تجربة وليست ضمان نجاح تحت حد ذاكرة iOS. يلزم هاتف فعلي لاختبار الذاكرة والحرارة والبطارية وسرعة العربية ووضع الطيران.
- ثماني حالات اصطناعية فقط لا تكفي لاعتماد تعليمي. ظهرت إجابة تعريف أقل دقة في Swift؛ لا حفظ تلقائي لمحتوى مولد.
- يستخدم MLX GPU عبر Metal حيث يتاح. لا اختبار Neural Engine ولا نموذج Core ML مخصص. لا تحول استخراج كلمات NaturalLanguage إلى ادعاء LLM.
- أوزان تالفة بالحجم نفسه بعد التحقق لا تُكتشف بواسطة علامة الجاهزية وحدها؛ الحذف وإعادة التنزيل يعيدان SHA-256 كاملًا. التحميل الفعلي قد يرفض الملف التالف، لكنه ليس ضمان تحقق تشفيري عند كل فتح.
- مسار xtool يحافظ على وظائف التطبيق الأخرى ومحرك Apple؛ اعتماديات MLX الحالية مضافة إلى XcodeGen فقط.
