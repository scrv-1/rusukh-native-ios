## ماذا يشغّل CI الجديد، وماذا لا يشغّل

الملف `.github/workflows/expo-preview.yml` يعمل عند `push` و`pull_request` على `ubuntu-latest` وNode 22، داخل `expo-preview`:

1. `npm ci`
2. `npm run typecheck`
3. `npm test` (ترجمة اختبارات TypeScript ثم `node --test`)
4. `npm run test:ui` (Jest)

سير `iOS - SwiftUI build and simulator preview` يبقى `workflow_dispatch` على مشغّل `xcode-27`. نجاح اختبارات Expo لا يثبت بناء Swift ولا تشغيل الآيفون.
