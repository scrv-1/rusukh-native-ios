# رُسوخ 0.2 — مساحة الطالب القابلة للتخصيص

المصدر الأساسي aa2339d6308f84b577b83e9de897c1996bd523c1، فرع التحديث work/expo-custom-workspace-20261102. لا تعديل على مشروع SwiftUI.

## التغيير
- الرئيسية تعرض المراجعة والملاحظات افتراضيًا. التخصيص يتيح إظهار/إخفاء خمسة أقسام، تقديمها وتأخيرها، عرضًا مختصرًا أو مريحًا، وإعادة الافتراضي.
- حفظ اختيارات الواجهة في جدول meta القائم، بمفتاح workspace.v1. لا ترحيل للجداول ولا حذف لبيانات الدراسة. إلغاء التخصيص لا يحفظ المسودة.
- زر كل الأدوات ثابت؛ تبقى الأدوات المخفية قابلة للفتح. الشريط يثبّت أول ثلاث صفحات مفعلة مع الرئيسية والإعدادات.
- استيراد TXT/MD/SRT/VTT من منتقي النظام حتى 1 MiB وUTF-8، ثم معاينة وتعديل قبل الحفظ. التوقيتات محفوظة. تصدير الملاحظة Markdown عبر المشاركة إلى الملفات.
- بحث عربي يتجاهل التشكيل والتطويل واختلاف الألف، ويدعم كلمات البحث بترتيب مختلف.
- تحديث استحقاق المراجعة عند العودة من الخلفية، وكل 30 ثانية أثناء الجلسة، وعند تحديث البيانات.
- حفظ الملاحظة والبطاقات المستخرجة داخل transaction واحدة، مع منع الضغط المتزامن. حد المصدر يشمل ترويسته ويطابق حد النسخة الاحتياطية.

## التحقق الفعلي في Linux
- قبل التعديل: 21 اختبارًا ناجحًا.
- بعد التعديل: 36 اختبار محرك/ملفات/إعدادات/SQL ناجحًا؛ SQLite حقيقية عبر Node مع إغلاق وإعادة فتح، وفشل محقون للتحقق من rollback.
- 7 اختبارات تفاعل React Native ناجحة: إخفاء الجميع وإعادة الفتح، إلغاء/استعادة، فشل الحفظ وإعادته، حفظ الترتيب والكثافة، إلغاء استيراد، تحديث موعد المراجعة عند العودة، واستحقاق البطاقة الجديدة فور حفظها.
- TypeScript: ناجح.
- تصدير iOS: ناجح، 802 وحدة، حزمة Hermes نحو 2MB. هذا تجميع JavaScript وليس بناء Xcode أو تثبيتًا.
- سجلات الاختبار في evidence/. اختبارات المكونات تستخدم محاكاة واجهات النظام والتخزين؛ اختبار SQL منفصل وحقيقي على Linux.

## اختبار الطالب على الآيفون
1. افتح المشروع من Expo Go بالحساب السابق وأعد تحميله.
2. تحقق من عنوان «مساحتي» و«تخصيص مساحتي» والإصدار 0.2 في الإعدادات.
3. أخفِ المراجعة، قدّم الملاحظات، اختر مختصر ثم احفظ. أعد فتح المشروع وتحقق من بقاء الاختيار.
4. افتح كل الأدوات وتحقق أن المراجعة المخفية وملاحظاتك ما زالت موجودة.
5. افتح مصادري واستورد TXT أو SRT تجريبيًا؛ ألغِ مرة ثم احفظ مرة. صدّر الملاحظة إلى الملفات.

لا نموذج ذكاء محلي في Expo Go، ولا تنزيل تلقائي من YouTube أو استخراج PDF في هذا التحديث. تفريغ الفيديو المستورد نص يقدّمه الطالب وليس فهمًا للصورة أو توليد أسئلة. لا سحب لترتيب الأدوات بعد؛ زرا تقديم وتأخير متاحان. إعدادات المساحة محلية ومنفصلة عن نسخة المحتوى JSON. لم يُختبر التحديث بعد على آيفون حقيقي، ولا VoiceOver أو الخط الكبير أو منتقي iCloud فعليًا. لا اشتراكات أو خدمات مدفوعة مفعّلة.
