# رُسوخ — نسخة Expo للمعاينة

الإصدار **0.4.2**، 3 نوفمبر 2026. هذه نسخة React Native لتجربة رُسوخ داخل Expo Go، إلى جانب مشروع SwiftUI الأصلي في المستودع. تشغيلها داخل Expo Go لا يثبت تثبيت تطبيق رُسوخ مستقل على الآيفون.

تضيف هذه النسخة مصادر PDF وYouTube، والكاميرا والتسجيل المحلي، والتذكير اليومي، ومختبر استدلال محلي تجريبي. بقيت الملاحظات والروابط والشبكة والبطاقات والمسودات وتخصيص الواجهة في المشروع الحالي. تقرير التنفيذ وحدود التحقق في [RELEASE_0.4.md](RELEASE_0.4.md).

## ما يمكن تجربته

| الجزء | السلوك الموجود | حدّه الحالي |
|---|---|---|
| مساحة الدراسة | إظهار الأدوات وإخفاؤها وترتيبها واختيار كثافة العرض؛ لا يحذف الإخفاء بيانات الدراسة | الأدوات الجديدة، ومنها المساعد، مخفية افتراضيًا حتى يختارها الطالب |
| الملاحظات والدراسة | حفظ SQLite، مسودة قابلة للاستعادة، بحث عربي، روابط وشبكة، بطاقات واختبارات وجدولة مراجعة | الجدولة الحالية مبسطة وليست FSRS |
| مصادري: PDF | اختيار ملف، استخلاص النص محليًا، معاينة الصفحات والتنبيهات ثم فتح مسودة | 10 MiB و 50 صفحة؛ لا OCR؛ بعض ملفات العربية تحتاج تصحيح ترتيب النص يدويًا |
| مصادري: YouTube | رابط فيديو صحيح مع تفريغ يقدّمه الطالب بصيغة SRT/VTT/TXT أو يلصقه؛ روابط زمنية واستخراج س/ج المكتوبة | لا تنزيل تلقائي للفيديو أو الترجمة، ولا توليد أسئلة من السرد بهذه الأداة |
| مصادري: الوسائط | التقاط/اختيار صورة، تسجيل صوت، مكتبة محلية واستماع ومشاركة كل ملف | لا تحويل كلام إلى نص؛ ملفات الوسائط ليست داخل نسخة JSON الاحتياطية |
| التذكير | تذكير محلي يومي اختياري من الإعدادات، متوقف افتراضيًا | تسليم الإشعار على الآيفون لم يُتحقق منه بعد |
| مساعد الدراسة | Wllama/llama.cpp يعمل على CPU، ونموذج GGUF يختاره الطالب؛ مراجعة النتيجة قبل حفظها | تجريبي؛ نجحت حالتان عربيتان والإلغاء في Chrome للمحرك السابق، ولم يُعد الاستدلال بعد رقعة 0.4.2 ولم يُثبت تشغيله داخل Expo Go على الآيفون |

واجهة المصادر تعرض أداة واحدة في كل مرة. PDF والمساعد لا يحمّلان محركهما عند بدء التطبيق؛ ما زالت الموارد المضمّنة تزيد حجم حزمة JavaScript، ويجب قياس أثرها على الهاتف.

## تشغيل المشروع والتحقق منه

نفّذ من مجلد `expo-preview` في بيئة Node معتمدة وضمن الحصة المجانية:

```sh
npm ci
npm test
npm run test:ui
npm run typecheck
npx expo install --check
npx expo-doctor
npx expo export --platform ios --output-dir dist-v042
```

مختبر الذكاء له اعتماديات تطوير وملف قفل منفصلان؛ `npm ci` في جذر Expo وحده لا يثبتهما:

```sh
cd ai-lab
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
```

بعد العودة إلى مجلد `expo-preview`، شغّل الخادم:

```sh
npx expo start --tunnel
```

افتح الرابط أو QR الفعلي الناتج من الخادم في Expo Go المتوافق مع SDK 58. رابط النفق مؤقت ويتوقف مع الخادم/Codespace. استخدم جلسة Expo الحالية إن كانت صالحة؛ عند طلب الدخول استخدم واجهة تسجيل الدخول الرسمية، ولا ترسل كلمة مرور أو رمزًا في المحادثة. لا توجد خطوة شراء أو بناء EAS مدفوع مطلوبة لتجربة هذه النسخة.

## تجربة قصيرة على الآيفون

1. افتح التخصيص وأظهر «مصادري». أخفِ أداة أخرى ثم أعد إظهارها وتحقق من بقاء ملاحظاتك.
2. أنشئ ملاحظة، أغلقها مع حفظ المسودة، وأعد فتح التطبيق واستعدها، ثم احفظها كملاحظة.
3. جرّب PDF نصيًا صغيرًا ثم PDF من صور فقط. راجع النص وتنبيه الصفحات قبل الحفظ؛ لا يُفترض أن تستخرج الصور نصًا.
4. الصق رابط YouTube وتفريغًا صغيرًا فيه س:/ج:، وراجع السؤال والمصدر والتوقيت قبل إنشاء البطاقات.
5. التقط صورة وسجّل مقطعًا قصيرًا، ثم أعد فتح المكتبة واستمع وشارك ملفًا إلى تطبيق «الملفات». اختبر رفض الصلاحيات أيضًا.
6. فعّل تذكيرًا لبضع دقائق لاحقة، أغلق الشاشة وتحقق من وصوله، ثم ألغِه. هذه خطوة اختبار جهاز، وليست نتيجة مثبتة مسبقًا.
7. صدّر نسخة JSON تجريبية قبل اختبار استعادتها؛ الاستعادة تستبدل محتوى الدراسة بعد التأكيد. صدّر الوسائط منفردة.
8. إن أردت اختبار المساعد، أظهره من التخصيص. اضغط «فتح تنزيل النموذج الرسمي»، واحفظ ملف GGUF في «الملفات»، ثم عد واختره داخل المحرك. الملف نحو **639 MB / 610 MiB** ولا يُنزّل تلقائيًا؛ قد يستهلك باقة الإنترنت. اتبع [تعليمات المختبر](ai-lab/README.md) للتحقق من مصدر النموذج وتجربته؛ يمكن للنظام إنهاء العملية عند ضغط الذاكرة.

## حفظ البيانات والخصوصية

الملاحظات والبطاقات والمراجعات في SQLite. حد نسخة JSON هو 15 MiB من UTF-8، وتُرفض النسخة غير الصالحة قبل استبدال البيانات. المسودة وتفضيلات الواجهة والتذكير لا تدخل نسخة محتوى الدراسة الحالية. تصدير JSON يخص محتوى الدراسة فقط. خيار «حفظ نسخة مع الوسائط في الملفات» ينقل مجلدًا يشمل الصور والصوت وتفضيلات مظهر آمنة، مع استثناء النموذج والمسودات والتذكيرات. الصور والصوت داخل بيانات التطبيق، ويمكن أيضًا مشاركة كل واحدة كملف مستقل؛ حذف التطبيق/بيانات المضيف قد يحذفها ما لم تصدّرها.

قراءة PDF ومعالجة التفريغ وحساب النموذج تجري محليًا. فتح رابط YouTube إجراء منفصل يفتح الخدمة الخارجية. النموذج غير مضمّن ولا يُنزَّل تلقائيًا؛ اختيار ملف موجود في iCloud قد يطلب تنزيله بواسطة النظام. لا تُرسل نصوص الدراسة إلى API ذكاء سحابي في هذا التنفيذ.
