# رُسوخ — نسخة Expo للمعاينة

تحديث 2 نوفمبر 2026 — الإصدار 0.2.0. هذه نسخة React Native موجودة سابقًا، مستقلة عن مشروع SwiftUI في المستودع الخاص. لم تُنقل إليها تحسينات التطبيق الأصلي الأخيرة.

## ما جرى التحقق منه

راجع `VALIDATION_2026-11-01.json` للمخرجات الفعلية ورموز الخروج. جرى تثبيت الحزم في Linux، ومحاذاة React Native إلى 0.88.1 وTypeScript إلى ~6.0.3، وإضافة expo-font المطلوب من expo-symbols، وإصلاح إعداد تجميع اختبارات TypeScript 6. أضيف package-lock.json لتثبيت الاعتماديات.

أرسل المستخدم صورة النسخة الأولى تعمل داخل Expo Go على آيفونه. اختبارات تحديث 0.2 الحالية موضحة في RELEASE_0.2.md؛ تجميع حزمة JavaScript واختبار المكونات على Linux لا يثبتان تشغيل هذا التحديث على الهاتف.

## الميزات الموجودة في المصدر

ملاحظات عربية، روابط بعناوين الملاحظات، شبكة معرفة، بطاقات، جدولة مبسطة، اختبارات اختيارية، وتخزين SQLite مع استيراد وتصدير JSON. الاستيراد يستبدل البيانات بعد التأكيد؛ لا يتضمن استرداد ودمج مشروع SwiftUI الجديد. هذه النسخة لا تحتوي محرك الذكاء المحلي MLX أو تكامل الكاميرا والصوت وPDF الموجود أو الجاري تطويره في النسخة الأصلية.

## مسار التجربة

1. تثبيت Expo Go من App Store وتحديثه لإصدار متوافق مع SDK 58. صفحة المتجر السعودي المعاينة في 1 نوفمبر تعرض الإصدار 58.0.5. يلزم مطابقة الإصدار المثبت فعليًا على الهاتف.
2. في بيئة Node سحابية مسموحة ضمن الحصة المجانية: تثبيت المشروع وفحصه بالأوامر أدناه. راجع الحصة قبل إنشاء خدمة ولا تفعّل فوترة.
3. تسجيل الدخول الآمن إلى Expo CLI وإلى Expo Go بالحساب نفسه. لا ترسل كلمات مرور أو رموز أو مفاتيح في المحادثة.
4. تشغيل خادم يصل إليه الآيفون ثم فتح رابط Expo أو QR الناتج فعلًا من الخادم. الرابط مرتبط ببقاء الخادم يعمل؛ ليس نشرًا دائمًا.
5. على الهاتف: إنشاء ملاحظة، إعادة فتحها، مراجعة بطاقة، تجربة البحث والشبكة والتصدير والاستيراد على بيانات تجريبية.

```sh
npm ci
npm test
npm run test:ui
npx tsc --noEmit
npx expo install --check
npx expo-doctor
npx expo login --browser
npx expo start --tunnel
```

نجح ربط CLI في Codespaces بحساب Expo نفسه الذي استخدمه الطالب في النسخة الأولى، عبر تدفق تسجيل الجهاز الرسمي. لا يلزم تسجيل دخول جديد ما دامت الجلسة صالحة. رابط النفق مؤقت ويتوقف عند توقف Codespace.
