# إصلاح مسارات الوسائط والتذكير

أُصلحت D004 وD005 وD007 وX205 في الملفات المسجلة داخل result.json. الدليل البرمجي: 77 اختبارًا ناجحًا في خمس مجموعات وفحص TypeScript ناجح. ملفات red تحفظ الفشل قبل الإصلاح؛ targeted-tests.txt يحفظ نتيجة التحقق النهائية.

النقل إلى المحذوفات قابل للاستعادة، ويحتفظ بالمساحة حتى يختار المستخدم الحذف النهائي بتأكيد مستقل. لا تُحذف المحذوفات تلقائيًا ولا تدخل النسخ الاحتياطية الجديدة. نسخ المصدر خارج التطبيق لا تتغير.

المكتبة تنشر payload الجديد بعد نسخ مرحلي وفحص الحجم. استعادة الملفات القديمة بلا metadata لا تثبت اكتمال محتواها أو بياناتها الأصلية، ولذلك تحمل اسمًا وتحذيرًا يوضحان أنها مستعادة. فشل النقل يحتفظ بالملف في المكتبة أو في المحذوفات مع طريق استعادة. إذا نجح الحذف النهائي للملف وفشل تنظيف metadata، تعرض الواجهة هذين الأمرين بوضوح.

عمليات filesystem المتعددة ليست ذرية. الاختبارات تستخدم موائمات وهمية ولم يُختبر iPhone أو VoiceOver فعليًا. راجع result.json لتفاصيل الحالات وحدود الدليل واختبارات القبول المطلوبة على الجهاز.
