## تقدم جزئي لا يحتسب إغلاقًا

- **S006 ، ويضم A008:** اعتماد مسودة AI المستعادة يربط البطاقة بالمصدر الأصلي المطابق؛ تغير المصدر أو غيابه يمنع الاستخراج. إعادة فتح ملاحظة الأسئلة المحفوظة كنص لا تستعيد المنشأ البنيوي الكامل. معلومات إصدار المصدر والنموذج والشاهد لكل بطاقة ما زالت غير مكتملة.
- **D002:** إنقاذ SQLite متحقق حتى 512MiB يشمل الدراسة و meta والمسودات ونقاط الرجوع. لا استعادة SQLite داخل التطبيق، ولا وسائط في الملف؛ حد JSON15MiB باقٍ. ليس مسار نسخ واستعادة مكتملًا داخل المنتج.
- **X207:** حقل رابط YouTube أصبح LTR ؛ تحرير المؤشر واللصق والنطق بلوحة عربية/إنجليزية على iPhone غير مختبر. يبقى بند الجهاز مفتوحًا.
- **R005:** صار bootstrap الحقيقي مغطى بخمس حالات تشمل فشل تهيئة SQL ثم إعادة المحاولة. المخطط القديم ممثل ب fixtures ؛ لم تُثبت ملفات قواعد فعلية لكل إصدار تاريخي أو كل ترحيل. لا نكرر ادعاء أن bootstrap لم يختبر، ولا نعلن إغلاق جميع مخاطر الترحيل.
