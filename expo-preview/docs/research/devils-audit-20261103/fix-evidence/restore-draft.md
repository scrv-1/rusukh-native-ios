# D003 — حماية المسودة قبل استبدال بيانات الدراسة

## العَرَض والدليل

كانت `finishStudyRestore()` تمحو `noteDraft.v1` بعد نجاح استيراد JSON أو المجلد أو استعادة نقطة رجوع. هذه المسودة ليست ضمن نسخة الدراسة أو نقطة الرجوع. دليل التدقيق السابق: `../data-evidence/draft-audit.ui.test.jsx`.

قبل الإصلاح فشلت 15 حالة ونجحت 9 من مجموعة تضم 24 اختبارًا: `restore-draft-red.log`. شمل الفشل حذف مسودة محرر مغلق، ونجاح استعادة قديمة بعد ظهور مسودة أحدث، وعدم فحص خانة المسودة عند الالتزام بالاستبدال.

## التعديل

- مسار `replaceStudy()` مشترك لعمليات الاستبدال الثلاث.
- يمنع الاستبدال عند فتح محرر ملاحظة أو بطاقة، أو وجود مسودة مسترجعة، أو تحميلها/حفظها، أو فشل قراءتها.
- يستخدم مرجعًا حيًا للحالة؛ لا يعتمد على الحالة التي التقطها منتقي الملفات أو تنبيه قديم.
- يقرأ `noteDraft.v1` من قاعدة البيانات وقت الالتزام تحت قفل العملية، ثم يعيد فحص الحالة الحية.
- يحمي أي قيمة غير `null`، بما فيها القيمة التالفة التي لا يمكن اعتماد خلوّها.
- يمنع فتح محرر أثناء انتظار فحص الاستبدال؛ ويضبط حالة فتح المحرر مباشرة لحماية الاستدعاءات في الدور نفسه قبل إعادة رسم React.
- لا يمحو المسودة بعد الاستعادة، ولا يعيد ربط معرف تحرير قديم بملاحظة مستوردة.
- بقي قفل العمليات وحاجز فشل تحديث العرض كما هما.
- الرسالة تشرح حفظ الملاحظة، أو تصدير المسودة **والتأكد من وجود الملف** ثم تجاهلها صراحة من الرئيسية. فتح قائمة المشاركة أو إلغاؤها ليس إثبات تصدير.

## التحقق الفعلي

```text
npx jest --runInBand tests/backup-app-integration.ui.test.jsx tests/draft-integration.ui.test.jsx
37 passed: 27 restore integration + 10 existing draft integration
npx tsc --noEmit
PASS
git diff --check
PASS
```

الأدلة النهائية: `restore-draft-green.log` و`restore-draft-typecheck.log`.

تتضمن الحالات: المسارات الثلاثة مع مسودة محررها مغلق؛ السماح بالاستعادة عند خلو الحالة وقاعدة البيانات؛ مسودة أحدث أثناء اختيار JSON؛ تنبيه نقطة رجوع قديم؛ callback مجلد قديم؛ محرر بطاقة؛ فشل قراءة المسودة؛ تحميلها الأولي المعلّق؛ فشل قراءتها الأولية؛ سباق فتح المحرر في الدور نفسه؛ محاولة فتح محرر خلال فحص قاعدة بيانات بطيء؛ وقيمة مسودة تالفة.

استُبدلت توقعات الاختبارات القديمة التي كانت تنتظر مسح المسودة دون تصريح. تستعمل fixtures مساحة `simple` محفوظة لتمثيل مستخدم قديم، وأصبح عنوان الرئيسية في App «مساحتي» بالتنسيق مع تغيير StudyHome.

## الحدود

هذه اختبارات React Native مع `useNoteDraft` وApp الحقيقيين وموائم تخزين وهمي؛ لا تثبت iCloud أو منتقي ملفات آيفون. لم يُغير مخطط التخزين أو التنفيذ الأصلي للمعاملات، ولم تجر اختبارات SQLite إضافية في هذه الدفعة.

في استيراد المجلد قد تُدمج ملفات الوسائط قبل وصول التنفيذ إلى `restoreStudy`. الحاجز يمنع استبدال **بيانات الدراسة النصية** عند وجود المسودة؛ لا يدّعي ذرية جميع ملفات المجلد، ولا يحذف وسائط سبق دمجها.

لا ينشئ التعديل أرشيف مسودات. على المستخدم حفظ المسودة كملاحظة، أو تصديرها والتحقق من الملف ثم تجاهلها صراحة، قبل استبدال المكتبة.
