# رُسوخ: استخدام مباشر وتخصيص آمن

المشكلة: إضافة أول محتوى تأتي بعد أقسام طويلة، وإخفاء الأقسام يغير شريط التنقل، والأدوات والإعدادات التقنية تحتاج بحثًا يدويًا.

النتيجة المطلوبة: الرئيسية تعرض الإضافة والبحث أولًا؛ التنقل ثابت؛ كل الأدوات متاحة دائمًا؛ قوالب ترتيب قابلة للتعديل بلا حذف بيانات؛ لصق مصدر مباشرة؛ إرشاد صادق لإعداد النموذج المحلي.

- نحافظ على Expo وSwiftUI الموجودين؛ هذه الدفعة تعدل Expo فقط.
- بلا تبعيات جديدة أو خدمات مدفوعة أو تغيير الفوترة.
- لا ندّعي OCR أو جلب نص YouTube تلقائيًا أو FSRS أو اختبار iPhone.
- تفضيلات workspace.v1 تبقى قابلة للقراءة والاستيراد؛ القوالب تغيّر العرض فقط.
- النموذج لا يصبح جاهزًا بمجرد عرضه في القائمة؛ تنزيله الخارجي ليس مدير تنزيل مدمجًا.
- البحث: 100 نصيحة و50 رابط فيديو، مع مستوى الوصول والمصدر وقرار التطبيق، وملحق دورات الصورة.
- قرارات قصيرة مميزة، دون تكرار لزيادة العدد.
