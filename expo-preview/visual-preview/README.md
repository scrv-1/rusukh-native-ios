# مختبر رُسوخ البصري

معاينة متصفح منفصلة تبدأ بذاكرة فارغة: لا مواد، لا بطاقات، ولا أقسام مضافة إلى الرئيسية. لا تدخل في نقطة تشغيل App ولا تفتح SQLite. لا يحفظ المختبر شيئًا بعد إعادة التحميل.

المكوّنات المستعملة مباشرة من المنتج: `StudyHome` و`ToolsScreen` و`StudyQuiz` و`WorkspaceEditor` و`KnowledgeGraph` و`ui`. الباقي موصلات محاكاة للمواد والبطاقات في الذاكرة؛ ليست نسخة كاملة من التطبيق. لا استيراد ملفات أصلي أو PDF أو كاميرا أو صوت أو نموذج AI أو مراجعة مجدولة في هذا المختبر.

«تحميل أمثلة اختيارية» يضيف ثلاث مواد وبطاقاتها مرة واحدة في جلسة المختبر، ولا يضيف أقسامًا إلى الرئيسية. «بدء مختبر فارغ» يمسح ذاكرة المختبر وتفضيلاته فقط. كل الأعداد مشتقة من البيانات؛ لا عدادات بطاقات أو مراجعات مصطنعة.

المسارات الموصولة:

1. مساحتي ← إضافة أداة ← ToolsScreen الفعلية: بحث، فتح الأداة، وإضافة قسم إلى المساحة أو إزالته.
2. إضافة مادة ← إدخال نص ← مراجعة المادة ← حفظها فقط أو استخراج س/ج المكتوبة بواسطة المحلل الفعلي.
3. موادي ← إضافة بطاقة يدويًا ← حفظ البطاقة ← تدريب الاسترجاع الفعلي.
4. التدريب ← كشف الإجابة ← تقييم ذاتي ← ملخص ← فتح المصدر والعودة دون فقد النتيجة. يبقى StudyQuiz mounted أثناء محرّر المصدر.
5. الأدوات ← شبكة أفكاري ← فتح مادة من الشبكة الفعلية. إعادة تسمية مادة في المختبر تعيد توجيه روابطها في الذاكرة.
6. بطاقاتي ← تعديل البطاقة؛ يحفظ التعديل بيانات الجدولة الموجودة في الذاكرة. تحديث مادة لا يحدّث إجابة بطاقة موجودة تلقائيًا داخل harness؛ استخدم تعديل البطاقة. هذه حدود المحاكاة، وليست وصفًا لسلوك App.

التشغيل المعتاد، عند وجود اعتماديات الويب المعلنة مسبقًا في بيئة الويب:

```sh
npm start
```

المنفذ المعلن 8082. بيئة Codespaces الحالية لها إعداد Vite سابق يتولّى الوكيل الرئيسي تشغيله وتصويره. لم يُغيَّر إعداد التشغيل أو package/lock ولم تُثبّت أي مكتبة ضمن هذا التحديث. لا تثبّت نسخة React ثانية داخل هذا المجلد.

التحقق الساكن:

```sh
node node_modules/typescript/bin/tsc --noEmit -p visual-preview/tsconfig.json
```

حدود الدليل: الصور ناتجة عن متصفح، وليست لقطات محاكي أو آيفون. لا يثبت المختبر لوحة مفاتيح iOS أو VoiceOver أو المشاركة أو الصلاحيات أو التخزين أو أداء الجهاز. أزرار عرض 320/390 تغيّر عرض الإطار فقط؛ المكوّنات التي تستعمل `useWindowDimensions` تقرأ viewport المتصفح الحقيقي. غيّر viewport أيضًا عند تقييم نقاط التحول المتجاوبة. تكبير المتصفح لا يساوي Dynamic Type.
