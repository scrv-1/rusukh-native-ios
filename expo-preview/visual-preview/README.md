# مختبر رُسوخ البصري

معاينة تطوير منفصلة، لا تدخل في نقطة تشغيل تطبيق Expo Go. تعرض المكوّنات الأصلية الموجودة `StudyHome` و`WorkspaceEditor` و`KnowledgeGraph` و`ui` باستخدام React Native Web.

البيانات كلها اصطناعية. تعديل الملاحظات وتفضيلات المساحة هنا في الذاكرة فقط وتُفقد بإعادة التحميل؛ لا تُفتح قاعدة SQLite ولا يُقرأ محتوى الطالب ولا تُستدعى خدمة ذكاء اصطناعي.

بعد توفير حزم الويب المتوافقة في `../node_modules`، شغّل من هذا المجلد:

```sh
npm start
```

المنفذ 8082. يعيد Metro استخدام اعتماديات المشروع الأم. لا تثبّت نسخة React ثانية داخل هذا المجلد.

خطوات الفحص:

1. جرّب الوضع الفاتح والداكن، والعرضين 320 و390.
2. افتح تخصيص المساحة، وأخفِ/أعد ترتيب الأدوات ثم احفظ. جرّب الإلغاء أيضًا.
3. افتح ملاحظة، وعدّل عنوانها، واحفظها في الذاكرة؛ يجب ظهور العنوان الجديد في الرئيسية.
4. افتح الشبكة، واستخدم قائمة العلاقات لفتح ملاحظة، وجرّب التكبير.
5. افحص الحقول والزر طويل النص. استخدم تكبير المتصفح لفحص القراءة؛ هذا لا يحاكي إعداد Dynamic Type في iOS.

حدود الدليل: الصور ناتجة عن متصفح ويب، وليست لقطات محاكي أو آيفون. لا يختبر المختبر التخزين الفعلي أو لوحة المفاتيح الأصلية أو VoiceOver أو المشاركة أو صلاحيات الجهاز أو سرعة/بطارية iOS. سجّل فحوص الأجهزة منفصلة.
